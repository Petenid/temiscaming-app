# Témiscaming community app

A free, independent app with local information for residents of Témiscaming, Quebec, in French and English. Not affiliated with the Ville de Témiscaming.

Built with Flutter for iOS, Android, Windows and macOS. Design and decisions: `DESIGN.md` (in the project docs); per-milestone specs in `specs/`.

## Status

Milestone 0 (foundation): first-launch language and collection-sector screens, a placeholder Today screen, and Settings.

## Run it

```
flutter pub get
flutter run -d windows     # or pick an Android emulator: flutter devices
```

## Test it

```
flutter analyze
flutter test --exclude-tags screenshots
```

Every push runs these on GitHub (see the Actions tab), plus an iOS compile check and screenshots of each screen in both languages.

## Setting up a Windows PC (notes from the first setup)

- **Tools:** Flutter, Git, VS Code with the Flutter extension, Visual Studio 2022+ with "Desktop development with C++", Android Studio (for the Android SDK and emulator), Node.js LTS (for the Firebase CLI).
- **Android NDK:** if a build fails with "sdkmanager did not install NDK x.y.z", install that exact version in Android Studio → SDK Manager → SDK Tools → tick *Show Package Details* → NDK (Side by side).
- **"running scripts is disabled":** `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
- **`flutterfire` not found:** add `%LOCALAPPDATA%\Pub\Cache\bin` to your PATH, or run `dart pub global run flutterfire_cli:flutterfire …`
- **Emulator from the terminal:** `flutter emulators --launch <id>`, then `flutter run -d emulator-5554`

## Firebase

Project `temiscaming-app`, Firestore in `northamerica-northeast1` (Montréal), Google Analytics off. `lib/firebase_options.dart` and `android/app/google-services.json` are generated by `flutterfire configure`; their keys identify the project and are safe to publish. Access is controlled by `firestore.rules` (currently: nothing readable or writable from the app). Deploy rule changes with `firebase deploy --only firestore:rules`.
